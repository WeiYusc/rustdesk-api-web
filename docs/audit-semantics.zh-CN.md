# 审计日志语义（管理员）

连接类型：0=远程控制、1=文件传输、2=端口转发、3=摄像头、4=终端。

文件方向以**被控端**为视角：0=被控端发送/控制端下载；1=被控端接收/控制端上传。未知类型或方向保留原始数字；不要把历史2/3强制重映射为已知文件方向。

`close_time=0` / 历史 `status=0`只表示未收到关闭上报，不证明连接仍在线。文件审计记录是操作上报，不证明传输完成或取消；不能据此推断成功、完整性或实时连接状态。

审计上报可匿名；nonce不存储、不去重，不保证exactly-once。API失败返回脱敏503，但界面有记录不证明真实客户端完整重试/关闭链路。旧数据的解释需要纠正，不改写记录来猜测方向。
